# Что такое pyfplib?

**pyfplib** — небольшая вдохновлённая Rust библиотека функционального программирования для Python. Она предоставляет явные типы для необязательных значений и операций, которые могут завершиться ошибкой, а также набор композируемых помощников для работы с последовательностями.

| Слой | Модуль | Назначение |
|---|---|---|
| **Option** | `pyfplib.option` | Представляет значение, которого может не быть: `Some(value)` или `Nothing()` |
| **Result** | `pyfplib.result` | Представляет успех или ошибку: `Ok(value)` или `Err(error)` |
| **Функции** | `pyfplib.functools` | Помощники для последовательностей: `fold`, `find`, `any_of`, `all_of` и другие |

## Принципы проектирования

- **Явное вместо неявного** — отсутствие значения и ошибка являются значениями, а не скрытыми проверками `None` или разбросанными исключениями.
- **Композируемость** — `map`, `and_then`, `or_else` и перегрузка операторов позволяют строить конвейеры, читаемые сверху вниз.
- **Вдохновлено Rust** — API следует привычной семантике `Option` и `Result` из Rust, адаптированной для Python.
- **Без зависимостей** — чистый Python без runtime-зависимостей, совместим с Python 3.12 и новее.

## Архитектура

```
                 pyfplib
        ┌───────────┼───────────┐
        │           │           │
     Option       Result     functools
   Some/Nothing  Ok/Err     fold, find,
        │           │        any_of, ...
        └─────┬─────┘           │
              │                 │
              ▼                 ▼
      композируемые конвейеры  помощники
```

`Option` и `Result` используют общую реализацию в `pyfplib._core` и реэкспортируются из `pyfplib.option` и `pyfplib.result`. Большинству пользователей достаточно пакета `pyfplib` верхнего уровня.
